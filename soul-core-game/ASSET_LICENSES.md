# Asset Licenses - Soul Core: The Great Decay

This file documents the sources and licenses for all assets used in the game.

## Core Principle
- All assets must be either:
  - Original creation
  - CC0 (Public Domain)
  - Public Domain
  - Free for commercial use with clear license
  - CC BY with attribution recorded here
